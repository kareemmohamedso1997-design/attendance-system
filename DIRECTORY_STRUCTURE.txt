🚀 QUICK START COMMANDS
═════════════════════════════════════════════════════════════

1. Install dependencies:
   npm install

2. Setup database:
   mysql -u root -p < database\schema.sql

3. Create .env file:
   copy .env.example .env
   (Edit with your database credentials)

4. Start server:
   npm run dev

5. Open browser:
   http://localhost:3000
