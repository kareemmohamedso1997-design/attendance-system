## 🚀 Quick Start (5 Steps, 20 Minutes)

### Step 1: Install Prerequisites
```bash
# Download Node.js from https://nodejs.org/
# Download MySQL from https://www.mysql.com/
```

### Step 2: Install Dependencies
```bash
cd "path-to-attendance-system"
npm install
```

### Step 3: Setup Database
```bash
mysql -u root -p < database\schema.sql
```

### Step 4: Configure .env
```bash
copy .env.example .env
# Edit .env with your database credentials
```

### Step 5: Start Server
```bash
npm run dev
```

Then open:
- **Employee Page:** http://localhost:3000
- **Admin Dashboard:** http://localhost:3000/admin

## 💡 Pro Tips

1. **For Windows Users:**
   - Use `copy .env.example .env` instead of `cp`
   - Use `\` instead of `/` in file paths
   - Use Command Prompt or PowerShell

2. **For Database:**
   - If MySQL password is blank, leave `DB_PASSWORD=` empty
   - Default port is 3306
   - Database name is `attendance_db`

3. **For Customization:**
   - Change `LATE_TIME` in `.env` to adjust late time
   - Add employees with SQL: `INSERT INTO employees (name) VALUES ('Name');`
   - Modify CSS files for different colors

4. **For Troubleshooting:**
   - Check `QUICK_REFERENCE.md` for common issues
   - Check browser console (F12) for JavaScript errors
   - Check server terminal for server errors
